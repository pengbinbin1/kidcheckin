# 兴趣班签到 · 部署指南

从零开始部署本应用到生产环境，全程使用免费服务。预计耗时 **30 分钟**。

---

## 前置条件

| 服务 | 用途 | 费用 |
|------|------|------|
| [Supabase](https://supabase.com) | 数据库 + 认证 + 推送 | 免费层足够 |
| [Cloudflare](https://dash.cloudflare.com) | 前端静态托管 | 免费 |
| GitHub | 代码托管（可选） | 免费 |

---

## 第一步：创建 Supabase 项目

1. 访问 [supabase.com](https://supabase.com)，注册/登录
2. 点击 **New Project**
3. 配置：
   - **Name**: `kidcheckin`（或任意名称）
   - **Database Password**: 设置一个强密码并**记下来**
   - **Region**: 选择离你最近的地域（推荐 `Southeast Asia (Singapore)`）
4. 点击 **Create new project**，等待约 2 分钟初始化完成

---

## 第二步：初始化数据库

1. 在 Supabase Dashboard 左侧菜单点击 **SQL Editor**
2. 点击 **New query**
3. 打开本项目 `supabase/migrations/0001_init.sql`，**复制全部内容**
4. 粘贴到 SQL Editor，点击 **Run**
5. 确认显示 `Success. No rows returned` 即可

---

## 第三步：配置认证

### 3.1 关闭邮箱确认（家庭自用推荐）

1. 左侧菜单 → **Authentication** → **Providers**
2. 点击 **Email** 展开
3. 关闭 **Confirm email** 开关
4. 点击 **Save**

> 开启此选项后注册无需邮件确认，直接登录成功。

### 3.2 配置站点 URL

1. 左侧菜单 → **Authentication** → **URL Configuration**
2. **Site URL**: 填写你部署后的域名（例如 `https://kidcheckin.pages.dev`）
   - 本地开发阶段可先填 `http://localhost:5173`
3. **Redirect URLs**: 点击 **Add URL** 添加：
   - `http://localhost:5173/**`（本地开发）
   - `https://your-domain.pages.dev/**`（生产环境）
4. 点击 **Save**

---

## 第四步：部署 Edge Functions

### 方式 A：使用 Dashboard（推荐新手）

#### 4.1 部署 `check-reminders`

1. 左侧菜单 → **Edge Functions**
2. 点击 **Create a function**
3. **Name**: `check-reminders`
4. 将编辑器内容替换为 `supabase/functions/check-reminders/index.ts` 的全部代码
5. 点击 **Deploy**

#### 4.2 部署 `calendar-ics`

1. 点击 **Create a function**
2. **Name**: `calendar-ics`
3. 将编辑器内容替换为 `supabase/functions/calendar-ics/index.ts` 的全部代码
4. 点击 **Deploy**

### 方式 B：使用 Supabase CLI

```bash
# 安装 CLI（如果未安装）
npm install -g supabase

# 登录
supabase login

# 在项目根目录执行
supabase functions deploy check-reminders
supabase functions deploy calendar-ics
```

## 第五步：生成并配置 VAPID 推送密钥

Web Push 需要一对 VAPID 密钥。**公钥和私钥必须配对使用。**

### 5.1 生成密钥对

```bash
npm run gen:vapid
```

输出类似：

```
PublicKey:  BJxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
PrivateKey: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 5.2 配置到 Supabase Secrets

在项目根目录执行：

```bash
supabase secrets set \
  VAPID_PUBLIC_KEY=BJxxxxxxxxxxxxxxxx \
  VAPID_PRIVATE_KEY=xxxxxxxxxxxxxxx
```

或在 Dashboard 中手动添加：
1. 左侧菜单 → **Edge Functions** → **Secrets**
2. 点击 **Add secret**
3. 添加 `VAPID_PUBLIC_KEY` 和 `VAPID_PRIVATE_KEY` 两条

### 5.3 配置到前端 `.env`

```env
VITE_VAPID_PUBLIC_KEY=BJxxxxxxxxxxxxxxxx
```

> ⚠️ **注意**：`.env` 中的公钥必须与 Supabase Secrets 中的 `VAPID_PUBLIC_KEY` **完全一致**。

## 第六步：配置定时任务

Supabase 内置 `pg_cron` 扩展用于定时执行 SQL。

### 6.1 每日课次生成（已自动配置）

Migration SQL 已包含此任务，无需额外操作。

### 6.2 课前提醒推送（需手动配置）

1. 在 Supabase Dashboard 左侧菜单点击 **SQL Editor**
2. **New query**
3. 粘贴以下 SQL（**替换其中的 `<YOUR_PROJECT_REF>` 和 `<YOUR_SERVICE_ROLE_KEY>`**）：

```sql
select cron.schedule(
  'kidcheckin-check-reminders',
  '*/5 * * * *',
  $$
  select net.http_post(
    url := 'https://<YOUR_PROJECT_REF>.supabase.co/functions/v1/check-reminders',
    headers := jsonb_build_object(
      'Content-Type', 'application/json',
      'Authorization', 'Bearer <YOUR_SERVICE_ROLE_KEY>'
    )
  );
  $$
);
```

4. 点击 **Run**

### 6.3 获取配置信息

- **`<YOUR_PROJECT_REF>`**: Dashboard → Settings → General → **Reference ID**
- **`<YOUR_SERVICE_ROLE_KEY>`**: Dashboard → Settings → API → **service_role** (secret)

## 第七步：部署前端到 Cloudflare Pages

### 方式 A：Git 连接部署（推荐）

1. 将代码推送到 GitHub 仓库
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com)
3. 左侧菜单 → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
4. 选择你的 GitHub 仓库
5. 配置构建设置：
   - **Framework preset**: `Vue.js`（或 None）
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
6. 展开 **Environment variables**，添加：

   | 变量名 | 值 |
   |--------|-----|
   | `VITE_SUPABASE_URL` | `https://your-project-ref.supabase.co` |
   | `VITE_SUPABASE_ANON_KEY` | Supabase Dashboard → Settings → API → anon public |
   | `VITE_VAPID_PUBLIC_KEY` | 第五步生成的公钥 |

7. 点击 **Save and Deploy**
8. 等待约 2 分钟，部署完成后获得域名如 `https://abc123.pages.dev`

### 方式 B：Wrangler CLI 直接部署

```bash
npm install -g wrangler

# 构建并部署
npm run build
npx wrangler pages deploy dist
```

## 家人使用流程

### 1. 注册并加入家庭

1. 家人打开应用链接
2. 点击「注册」，填写邮箱和密码
3. 登录后，输入家庭邀请码加入家庭
4. 现在全家人看到同一份数据

### 2. iPhone 添加到主屏幕

1. 在 Safari 中打开应用
2. 点击底部分享按钮 ⬆️
3. 向下滑动，点击 **添加到主屏幕**
4. 确认名称，点击 **添加**

### 3. 开启推送通知

1. 在「我的」→「提醒设置」中点击 **开启推送通知**
2. 系统弹窗点击 **允许**
3. 现在课前 N 分钟会收到推送提醒

### 4. 订阅系统日历（可选，双保险）

1. 在「我的」→「提醒设置」中点击 **查看** 日历订阅引导
2. 按照引导步骤在 iPhone **设置 → 日历 → 账户 → 添加订阅日历** 中粘贴链接
3. 课程会自动同步到系统日历，课前原生弹提醒

## 常见问题排查

### Q: 收不到课前提醒推送？

1. **检查是否添加到主屏幕**：iOS 只有在 PWA 安装后才支持 Web Push
2. **检查通知权限**：iPhone 设置 → 通知 → 找到应用 → 开启允许通知
3. **检查 VAPID 配置**：确认 `.env` 中的公钥与 Supabase Secrets 中的一致
4. **手动触发测试**：
   ```bash
   curl -X POST \
     https://your-project-ref.supabase.co/functions/v1/check-reminders \
     -H "Authorization: Bearer YOUR_SERVICE_ROLE_KEY"
   ```

### Q: 日历订阅不生效？

1. 确认使用的是正确的 `ics_token`（在数据库 `families` 表中可查看）
2. iPhone 日历 App → 底部「日历」→ 确认订阅日历已勾选
3. 下拉刷新日历列表

### Q: 签到时提示「已超出可签到时间范围」？

- 本应用限制现场签到仅能在 **开始前 2 小时** 到 **开始后 6 小时** 内操作
- 如果错过了时间窗口，请使用 **补签** 功能（需要管理员权限）

### Q: 忘记密码怎么办？

- 在登录页面点击「忘记密码」，通过邮箱重置
